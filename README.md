# منصة أبواب التطوير المهني للمعلمين

منصة تدريبية متكاملة تقدم ستة عشر باباً من أبواب التطوير المهني للمعلمين، مع نظام نقاط وشارات ومستويات، وخطط تطبيقية، ولوحة تحكم إشرافية كاملة.

---

## مكونات المنصة

| المكوّن | الوصف |
|---------|-------|
| صفحة رئيسية ترحيبية | تعريف بالمنصة وأبوابها الستة عشر |
| تسجيل المستخدمين | إنشاء حساب بالاسم واسم المستخدم وكلمة المرور |
| منصة المتدرب | 16 باباً تدريبياً، اختبارات قصيرة، نقاط وشارات ومستويات، مفضلة، خطط تطبيقية |
| دخول المشرف | صفحة مستقلة `/admin/login` بالبريد الإداري المعتمد |
| لوحة التحكم | متابعة المستخدمين ونقاطهم وشاراتهم وأبوابهم المنجزة وخططهم |
| داشبورد إحصائي | إجمالي المستخدمين، متوسط النقاط، أكثر الأبواب إنجازاً، عدد الخطط |

**حساب المشرف الوحيد المعتمد:** `a-z_2@hotmail.com` — لا يمكن إنشاء حسابات إدارية أخرى من الواجهة إطلاقاً.

## المتطلبات على الخادم

1. **Node.js** الإصدار 20 أو أحدث
2. **قاعدة بيانات MySQL** الإصدار 8 أو أحدث (أو MariaDB 10.5+)
3. **pnpm** لإدارة الحزم (أو npm)

---

## خطوات التثبيت والتشغيل

### 1) فك الضغط ورفع الملفات
ارفع محتويات هذا المجلد إلى الخادم (مثلاً في `/var/www/abwab`).

### 2) تثبيت الحزم
```bash
cd /var/www/abwab
npm install -g pnpm   # إن لم تكن pnpm مثبتة
pnpm install
```

### 3) إعداد قاعدة البيانات
أنشئ قاعدة بيانات فارغة في MySQL:
```sql
CREATE DATABASE abwab_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 4) إعداد ملف البيئة
```bash
cp .env.example .env
nano .env
```
عدّل القيم التالية:
- `DATABASE_URL`: رابط الاتصال بقاعدة البيانات
- `JWT_SECRET`: نص عشوائي طويل (مهم جداً للأمان)
- `ADMIN_DEFAULT_PASSWORD`: كلمة مرور المشرف — **غيّرها قبل أول تشغيل**

### 5) إنشاء الجداول
```bash
node setup-db.mjs
```

### 6) البناء والتشغيل
```bash
pnpm build
pnpm start
```
سيعمل الخادم على المنفذ 3000 (أو ما حددته في `PORT`).

> **ملاحظة:** حساب المشرف (a-z_2@hotmail.com) يُنشأ تلقائياً عند أول تشغيل للخادم بكلمة المرور المحددة في `ADMIN_DEFAULT_PASSWORD`.

### 7) التشغيل الدائم (موصى به)
```bash
npm install -g pm2
pm2 start dist/index.js --name abwab
pm2 save && pm2 startup
```

## ربط الدومين (Nginx)

مثال إعداد Nginx كوسيط عكسي مع الدومين الخاص بك:

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

ثم فعّل شهادة HTTPS المجانية:
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

> **مهم:** يجب تفعيل HTTPS لأن كوكيز الجلسات تتطلب اتصالاً آمناً في بيئة الإنتاج.

## استكشاف الأخطاء

- **الخادم لا يتصل بقاعدة البيانات:** تحقق من صحة `DATABASE_URL` ومن أن MySQL يعمل ويسمح بالاتصال.
- **دخول المشرف لا يعمل:** تأكد من أن الخادم أُقلع مرة واحدة على الأقل بعد إعداد قاعدة البيانات (لإنشاء الحساب الإداري تلقائياً)، وأنك تستخدم البريد `a-z_2@hotmail.com` مع كلمة المرور المحددة في `.env`.
- **الجلسة لا تُحفظ بعد الدخول:** تأكد من تفعيل HTTPS على الدومين.
- **نسيت كلمة مرور المشرف:** احذف صف المشرف من جدول `accounts` وأعد تشغيل الخادم مع `ADMIN_DEFAULT_PASSWORD` جديدة، أو حدّث الحقل مباشرة في قاعدة البيانات.
